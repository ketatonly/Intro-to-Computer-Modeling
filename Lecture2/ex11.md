### Exercise 11: Find largest and smallest positive normal numbers, $N_{\max}^n$ and $N_{\min}^n$ for the general set of floating point numbers $\mathbb{F}_{\beta, p}^{\check{e}, \hat{e}}$.

### Answer:

general set of floating point numbers $\mathbb{F}_{\beta, p}^{\check{e}, \hat{e}}$

So, all the numbers are: $\quad x = \pm (b_0.b_1b_2...b_{p-1})_\beta \times {\beta}^e \quad$ where e is between $\check{e}$ and $\hat{e}$.

We need to find all the normal numbers, that means b_0 must be nonzero, and to maximize it, we need $\beta -1$.

For the largest possible number, we need to maximize the exponent, so it must be $\hat{e}$

We need to maximize significand as well, which means that all the b-s up to b_{p-1} must be $\beta$ -1s 

That gives us:
$N_{\max}^n = ((\beta-1).(\beta-1)_1(\beta-1)_2...(\beta-1)_{p-1})_\beta \times {\beta}^{\hat{e}} $

For the smallest positive number, we need to minimize b_0 to the smallest nonzero number, so 1. We also need to minimze the rest of the bs, which gives us zeros for all the bs and the exponent must be $\check{e}$:

$N_{\min}^n = (1.0_10_2...0_{p-1})_\beta \times {\beta}^{\check{e}} $
