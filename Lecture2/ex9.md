### List all the normal numbers represented within the toy system. 

### Answer:
The toy number system:

$\mathbb{F}_{2,3}^{-1,2}$

So, all the numbers are: $\quad x = \pm (b_0.b_1b_2)_2 \times 2^e \quad$ where e is between -1 and 2.

We need to find all the normal numbers, that means b_0 must be nonzero, since we are in binary, the only choice for b_0 is to be 1.

$\quad x = \pm (1.b_1b_2)_2 \times 2^e$

For $e = -1$:

$ x = \pm (1.00)_2 \times 2^{-1} = 1 * \frac{1}{2} = \frac{1}{2} = \pm 0.5$

$ x = \pm (1.01)_2 \times 2^{-1} = (1 + \frac{1}{4}) * \frac{1}{2} = \frac{5}{8} = \pm 0.625$

$ x = \pm (1.10)_2 \times 2^{-1} = (1 + \frac{1}{2}) * \frac{1}{2} = \frac{3}{4} = \pm 0.75$

$ x = \pm (1.11)_2 \times 2^{-1} = (1 + \frac{1}{2} + \frac{1}{4}) * \frac{1}{2} = \frac{7}{8} = \pm 0.875$

For $e = 0$:

$ x = \pm (1.00)_2 \times 2^{0} = 1 = 1 = \pm 1$

$ x = \pm (1.01)_2 \times 2^{0} = (1 + \frac{1}{4}) = \frac{5}{4} = \pm 1.25$

$ x = \pm (1.10)_2 \times 2^{0} = (1 + \frac{1}{2}) = \frac{3}{2} = \pm 1.5$

$ x = \pm (1.11)_2 \times 2^{0} = (1 + \frac{1}{2} + \frac{1}{4}) = \frac{7}{4} = \pm 1.75$

For $e = 1$:

$ x = \pm (1.00)_2 \times 2^{1} = 1 * 2 = 2 = \pm 2$

$ x = \pm (1.01)_2 \times 2^{1} = (1 + \frac{1}{4}) * 2 = \frac{5}{2} = \pm 2.5$

$ x = \pm (1.10)_2 \times 2^{1} = (1 + \frac{1}{2}) * 2 = 3 = \pm 3$

$ x = \pm (1.11)_2 \times 2^{1} = (1 + \frac{1}{2} + \frac{1}{4}) * 2 = \frac{7}{2} = \pm 3.5$

For $e = 2$:

$ x = \pm (1.00)_2 \times 2^{2} = 1 * 4 = \pm 4$

$ x = \pm (1.01)_2 \times 2^{2} = (1 + \frac{1}{4}) * 4 = \pm 5$

$ x = \pm (1.10)_2 \times 2^{2} = (1 + \frac{1}{2}) * 4 = \pm 6$

$ x = \pm (1.11)_2 \times 2^{2} = (1 + \frac{1}{2} + \frac{1}{4}) * 4 = \pm 7$
