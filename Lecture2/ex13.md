### A normalized floating point number with precision p is expressed as follows $\quad x = \pm (b_0.b_1b_2...b_{p-1})_\beta \times {\beta}^e \quad$. Find the gap (distance) between 1 and the next larger floating point number. In the binary base this gap is given a special name, it is referred to as machine epsilon and are denoted by $ε_M$.

### Answer:
Number 1 in this form is given by:

$\quad x_1 = (1.0_10_2...0_{p-1})_\beta \times {\beta}^0 \quad$

And the next larger floating point number is:

$\quad x_2 = (1.0_10_2...1_{p-1})_\beta \times {\beta}^0 \quad$

The only difference between these numbers are the (p-1)th bit, so if we subtract $x_1$ from $x_2$, we will get:

$ε_M = \frac{1}{\beta^{p-1}}$

And for the binary base $\beta = 2\quad$ we have:

$ε_M = \frac{1}{2^{p-1}}$
